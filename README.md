# 🏨 Hotel Performance Analysis Dashboard

An interactive Hotel Performance Analysis Dashboard built using **Tableau Public**. This project analyzes hotel booking data to uncover trends in reservations, cancellations, guest behavior, and market segments through interactive visualizations.

## 📌 Key Insights

- 📈 Monthly booking trends for City Hotels and Resort Hotels.
- 🏨 Comparison of total bookings between City and Resort Hotels.
- 👥 Market segment analysis (Online TA, Offline TA/TO, Direct, Groups, etc.).
- 📅 Year-wise booking analysis (2015–2017).
- ❌ Hotel cancellation trends across different years.
- 🌙 Comparison of Week Night and Weekend Night stays.
- 🔁 Repeated guest analysis for both hotel types.

## 💡 Business Insights

- City Hotels account for the majority of bookings.
- Online Travel Agencies (Online TA) generate the highest share of bookings.
- Booking demand peaks during the middle of the year.
- Cancellation trends vary significantly across years.
- Week-night stays are considerably higher than weekend stays.
